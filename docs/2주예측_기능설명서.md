# 2주 예측 기능 설명서

> 작성일: 2026-05-15  
> 시스템 버전: v1.9.0  
> 대상: O&M 상세 페이지 > 2주 예측 탭

---

## 📋 개요

**2주 예측**은 풍력 발전소의 향후 14일(D+1 ~ D+14) 동안의 기상 조건과 발전량을 예측하여, 주간 운영 계획 및 정비 스케줄링을 지원하는 기능입니다.

### 주요 특징
- **예측 기간**: 14일 (2주)
- **예측 주기**: 1일 1회
- **대상 발전소**: 서남해(SNH), 월정(WJ), 탐라(TR)
- **터빈 수**: 발전소당 20호기 (WTG01 ~ WTG20, 정격 3MW)
- **데이터 소스**: JSON 파일 기반 실데이터 또는 랜덤 fallback

### 접근 경로

```
홈 대시보드 → 발전소 카드 클릭 → O&M 상세 페이지 → [2주 예측] 탭
```

### 탭 구조

```
O&M 상세 페이지
├── Overview
├── 하루 전 예측
├── 2주 예측          ← 본 문서 대상
│   ├── [발전소] 탭   ← 발전소 전체 예측
│   └── [터빈별] 탭   ← 터빈별 상세 예측
└── 3개월 예측
```

## 📊 발전소 탭 (발전소 전체 예측)

### 1. 기상 예측 (14일)

14일간의 기상 조건을 박스플롯 차트로 시각화합니다.

#### 표시 항목 (체크박스 조합)

| 항목 | Y축 범위 | 축 위치 | 기본 표시 |
|------|----------|---------|----------|
| 풍속 | 0 ~ 30 m/s | 좌축 | ✅ 항상 표시 (비활성 체크박스) |
| 기온 | -10 ~ 40 °C | 우축 | ☐ 선택 시 표시 |
| 파고 | 0 ~ 3.5 m | 우축 | ☐ 선택 시 표시 |

#### 시간대 필터 (라디오 버튼)

| 옵션 | 시간 범위 | 용도 |
|------|----------|------|
| 일간 전체 | 0 ~ 24시 | 전체 기상 조건 파악 |
| O&M 시간 | 08 ~ 18시 | 정비 작업 가능 시간대만 분석 |

#### 박스플롯 색상 기준

**풍속 (median 기준)**:
- 💧 하늘색: < 3 m/s (컷인 미달)
- 🔵 파란색: 3 ~ 6 m/s (저풍속)
- 🟢 초록색: 6 ~ 10 m/s (최적 구간)
- 🟠 주황색: 10 ~ 15 m/s (고풍속)
- 🔴 빨간색: ≥ 15 m/s (위험)

**파고 (median 기준)**:
- 🟢 초록색: < 0.8 m (양호)
- 🟠 주황색: 0.8 ~ 1.5 m (주의)
- 🔴 빨간색: ≥ 1.5 m (위험)

**기온 (median 기준)**:
- 🔵 파란색: ≤ 5°C (저온)
- 🟢 초록색: 5 ~ 30°C (적정)
- 🔴 빨간색: ≥ 30°C (고온)

#### 인터랙션
- 박스플롯의 특정 일자를 **클릭**하면 해당 일의 24시간 상세 O&M 패널이 열림

---

### 2. 14일 O&M 가능 여부 요약

기상 예측 아래에 표 형태로 14일간의 O&M 가능 여부를 한눈에 보여줍니다.

#### O&M 판단 기준

| 변수 | O&M 가능 기준 | 초과 시 상태 |
|------|-------------|-------------|
| 풍속 | ≤ 10 m/s | 🔴 O&M 불가 |
| 파고 | ≤ 1.5 m | 🔴 O&M 불가 |
| 최고기온 | ≤ 30°C | 🟡 조건부 |
| 최저기온 | ≥ 5°C | 🟡 조건부 |

#### 종합 판정

| 상태 | 조건 | 표시 |
|------|------|------|
| 🟢 양호 | 풍속 + 파고 + 기온 모두 충족 | 초록 배지 |
| 🟡 주의 | 풍속 + 파고 OK, 기온 미충족 | 노란 배지 |
| 🔴 불가 | 풍속 또는 파고 미충족 | 빨간 배지 |

#### 표 구성
- **행**: 종합 / 풍속 / 기온 / 파고
- **열**: D+1 ~ D+14 (실제 날짜 표시)
- **셀 값**: ✓ (기준 충족, 파란색) / ✗ (기준 미충족, 빨간색)

---

### 3. 인라인 상세 패널 (24시간 O&M 상세)

박스플롯에서 특정 일자를 클릭하면 해당 일의 24시간 상세 정보가 인라인으로 펼쳐집니다.

#### 구성 요소

1. **시간별 풍속 예측 차트** (라인 차트)
   - X축: 0시 ~ 23시
   - Y축: 풍속 (m/s), 최대 20
   - 포인트 색상: 풍속 구간별 색상 구분
     - 빨간색: < 3 m/s (발전 불가)
     - 주황색: 3 ~ 6 m/s (저풍속)
     - 초록색: 6 ~ 12 m/s (최적 발전)
     - 파란색: > 12 m/s (정격 출력)

2. **24시간 O&M 가능 여부 판단 테이블**
   - 시간대 필터 적용 (일간 전체 / O&M 시간)
   - 행: 종합(색상 바) / 풍속 / 기온 / 기온(저) / 파고
   - 열: 시간별 (0시~23시 또는 8시~17시)
   - 셀: ✓ / ✗ 표시

#### 닫기
- 우측 상단 [닫기] 버튼으로 패널 숨김

---

### 4. 발전량 예측

#### 주간 총 발전량 KPI (좌측 1/4)

| KPI | 설명 |
|-----|------|
| 1주차 예상 발전량 | D+1 ~ D+7 총 발전량 (MWh) |
| 2주차 예상 발전량 | D+8 ~ D+14 총 발전량 (MWh) |
| 정비 손실 발전량 | 정비 계획 입력 시 표시 (빨간 카드) |
| 정비 반영 예상 | 정비 손실 차감 후 예상 발전량 (초록 카드) |

#### 일일 총 발전량 차트 (우측 3/4)

- **차트 유형**: 라인 차트
- **X축**: 14일 (실제 날짜 M/D 형식)
- **데이터셋**:
  - 주황색 실선: 일일 총 발전량 (MWh)
  - 빨간색 점선: 정비 반영 발전량 (정비 계획 존재 시)
- **⚠️ 주의 알림**: "일평균 예측은 변동성이 크므로, 주간 경향성 및 변동성 파악 용도로 활용하십시오."

## 🔧 터빈별 탭

### 1. Overview (히트맵 + 랭킹)

#### 14일 × 20호기 발전량 히트맵

20개 터빈의 14일간 발전량을 색상 매트릭스로 시각화합니다.

**히트맵 모드 전환** (라디오 버튼):

| 모드 | 시간 범위 | 최대값 | 설명 |
|------|----------|--------|------|
| 일간 전체 | 0 ~ 24시 | 72 MWh | 3MW × 24h |
| O&M 작업시간 | 08 ~ 18시 | 30 MWh | 3MW × 10h |

**색상 범례** (5단계 절대값 기준):
```
0 → [연노랑] → [연초록] → [연파랑] → [파랑] → [진파랑] → 72 MWh (또는 30 MWh)
```

**셀 정보**:
- 상단: 발전량 (MWh, 굵은 글씨)
- 하단: 풍속 (m/s, 작은 글씨)
- 빨간 테두리 + 🔧: 정비 계획 입력된 셀

**열 구성**:
- 터빈명 (WTG #1 ~ #20): 클릭 시 상세 페이지 이동
- D+1 ~ D+14: 일별 발전량/풍속
- 합계: 14일 총 발전량
- 손실: 정비 계획에 의한 손실 발전량

#### 터빈별 14일 총 발전량 랭킹

히트맵 아래에 터빈별 총 발전량을 내림차순으로 정렬하여 표시합니다.

| 요소 | 설명 |
|------|------|
| 순위 | 1~3위 파란색, 하위 빨간색 |
| 터빈명 | WTG #N |
| 프로그레스 바 | 1위 대비 비율 (파란색/빨간색) |
| 발전량 | 14일 총 MWh |
| ⚠️ 경고 | 평균 대비 90% 미만 시 표시 |
| 스파크라인 | 14일간 발전량 추이 미니 차트 |

**인터랙션**: 터빈 행 클릭 시 상세 페이지로 이동

---

### 2. 터빈 상세 페이지

랭킹 또는 히트맵에서 특정 터빈을 클릭하면 상세 페이지로 전환됩니다.

#### 구성 요소

1. **[← Overview로 돌아가기]** 버튼
2. **터빈 제목**: "WTG #N 상세"
3. **주간 총 KPI**:
   - 1주차 총 발전량 (MWh)
   - 2주차 총 발전량 (MWh)
4. **일 평균 풍속 예측 차트** (14일)
   - 라인 차트, 풍속 구간별 포인트 색상
   - 기준선: 3, 6, 10, 15 m/s
5. **일간 총 발전량 차트** (14일)
   - 라인 차트, 파란색

---

### 3. 정비 계획 입력 (모달)

히트맵 셀을 클릭하면 정비 계획 입력 모달이 열립니다.

#### 모달 정보 표시
- 터빈명: WTG #N
- 날짜: YYYY-MM-DD
- 예상 발전량: N MWh
- 예상 풍속: N m/s

#### 입력 항목

| 항목 | 타입 | 옵션/기본값 |
|------|------|------------|
| 정비 유형 | 드롭다운 | 정기 점검, 고장 수리, 부품 교체, 특별 점검 |
| 시작 시간 | 시간 입력 | 기본 09:00 |
| 종료 시간 | 시간 입력 | 기본 17:00 |
| 메모 | 텍스트 | 자유 입력 |

#### 버튼
- **저장**: 정비 계획 저장 (localStorage)
- **삭제**: 기존 계획 삭제 (기존 이력 있을 때만 표시)
- **닫기**: 모달 닫기

#### 정비 손실 계산
- 실데이터 존재 시: 해당 터빈의 정비 시간대 실제 시간별 발전량 합산
- 실데이터 미존재 시: 정비 시간 × 5 MW/h (고정값)

## 🔄 프론트엔드 파생 계산

서버에서 제공하지 않는 데이터는 프론트엔드에서 실시간 계산합니다.

| 파생 항목 | 계산 방법 | 용도 |

| 터빈별 O&M 시간대 발전량 | hourly.power[day][8:18] 합산 | O&M 히트맵 |
| 터빈별 O&M 시간대 풍속 | hourly.wind_speed[day][8:18] 평균 | O&M 히트맵 |

| O&M 시간대 박스플롯 | hourly[8:18] 슬라이싱 후 stats 재계산 | 기상 박스플롯 |
| 정비 손실 발전량 | 정비 시간대 터빈별 hourly.power 합산 | 손실 KPI |

## 📋 사용 시나리오

### 시나리오 1: 주간 운영 계획 수립

1. 2주 예측 탭 진입
2. 발전소 탭에서 기상 박스플롯 확인 → 풍속/파고 추이 파악
3. O&M 요약 테이블에서 정비 가능 일자 식별 (🟢 일자)
4. 발전량 KPI로 주간 예상 발전량 확인

### 시나리오 2: 정비 스케줄링

1. 터빈별 탭 진입
2. 히트맵에서 저발전량 셀 식별 (연노랑 색상)
3. O&M 요약에서 해당 일자의 기상 조건 확인
4. 저발전 + 양호 기상 조건인 셀 클릭 → 정비 계획 입력
5. 손실 발전량 KPI 및 차트에서 정비 영향 확인

### 시나리오 3: 터빈 성능 모니터링

1. 터빈별 탭 > 랭킹에서 ⚠️ 표시된 저성능 터빈 확인
2. 해당 터빈 클릭 → 상세 페이지
3. 14일간 풍속/발전량 추이 분석
4. 풍속 대비 발전량이 낮은 경우 점검 필요 판단
